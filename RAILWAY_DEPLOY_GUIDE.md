## ⚡ Step-by-Step Instructions

### 1. Download & Extract ZIP
1. Admin Panel (`/sufyan-control`) sy **Download Bot Code ZIP** par click karein.
2. ZIP file aapke computer/mobile mein download ho jayegi (`SUFYAN-X-IK_MD_BOT_DEPLOYMENT.zip`).
3. Isay extract karein.

### 2. GitHub par Upload Karein
1. [GitHub.com](https://github.com) par ek new **Private Repository** banayein (e.g. `sufyan-xik-bot`).
2. Extracted files ko is repository mein upload / push karein.

### 3. Railway.app par Deploy Karein
1. [Railway.app](https://railway.app) open karein aur login karein.
2. **"New Project"** par click karein.
3. **"Deploy from GitHub repo"** select karein.
4. Apni banayi hui repository select karein (`sufyan-xik-bot`).
5. Railway automatically `Dockerfile` aur `railway.json` detect karega aur build start kar dega!

### 4. Variables (Optional)
Railway Dashboard mein **Variables** tab mein jayein aur yeh add karein:
- `PORT` = `3000`
- `NODE_ENV` = `production`
- `GEMINI_API_KEY` = (Aapki Gemini API Key agar AI features chaiye)

### 5. Generate Domain & Pair WhatsApp
1. **Settings** tab mein jayein aur **"Generate Domain"** par click karein (e.g. `sufyan-bot.up.railway.app`).
2. Apna generated link open karein:
   - Pair code hasil karein aur WhatsApp par link karein.
   - Admin Panel open karein: `https://your-domain.up.railway.app/sufyan-control`
   - Password: `SUFYANHYEE`
